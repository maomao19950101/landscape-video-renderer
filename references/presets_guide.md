# 风格预设参数指南与调色原理

## 一、14 项参数统一规范

| 参数名 | 物理意义 | 取值范围 | 调色作用 |
| :--- | :--- | :--- | :--- |
| `vignette_intensity` | 画圈暗角强度 | 0.0 ~ 1.0 | 控制背景压暗程度，数值越大视线收拢越紧 |
| `vignette_radius` | 聚光圈半径 | 0.3 ~ 0.8 | 占画面短边的比例，控制光圈覆盖范围 |
| `vignette_softness` | 羽化柔和度 | 0.2 ~ 0.9 | 数值越大边缘过渡越平滑无痕，越小边界越硬 |
| `brightness_subject` | 主体提亮幅度 | 0.0 ~ 0.3 | 圈内主体曝光提升，让主体跳出画面 |
| `contrast_subject` | 主体对比度增强 | 0.0 ~ 0.3 | 圈内细节反差增强，增强质感 |
| `bloom_enabled` | 柔光漫射开关 | true / false | 是否开启仙气/梦幻光晕薄纱 |
| `bloom_threshold` | 高光提取门槛 | 0.5 ~ 0.9 | 只有亮度高于此值的像素才会发光漫射 |
| `bloom_intensity` | 柔光强度 | 0.0 ~ 1.0 | 梦幻光晕叠加强度 |
| `bloom_radius` | 柔光扩散半径 | 5 ~ 50 px | 光晕扩散范围，越大越朦胧仙气 |
| `color_temp_shift` | 色温偏移 | -30 ~ +30 | 负值偏冷（青蓝），正值偏暖（金橙） |
| `saturation_adj` | 饱和度微调 | -0.3 ~ +0.3 | 负值低饱和高级灰，正值浓郁鲜艳 |
| `tint_shadows` | 暗部着色 | hex / None | 给阴影染色（如深紫、墨绿、冷青） |
| `tint_highlights` | 高光着色 | hex / None | 给高光染色（如淡粉、暖金、米白） |
| `grain_amount` | 胶片颗粒度 | 0.0 ~ 0.3 | 模拟 35mm 胶片质感噪点 |

## 二、9 款风格调色配方详解

### 1. INFP 浪漫梦幻 🦋（主打王牌）
* **视觉语言**：莫奈花园油画感、梦幻柔焦、少女心与治愈感。
* **调色逻辑**：高光提取后施加 30px 超大半径 Gaussian Blur，暗部染以微弱深紫（`#2d1b4e`），高光染以樱花淡粉（`#ffd4e5`），色温略微偏暖，配合 0.85 超高羽化光圈。
* **适用场景**：花海、落日余晖、湖面波光、微风草地、雨后反光。

### 2. INTJ 冷峻秩序 🧊
* **视觉语言**：冰岛冷调、性冷淡工业风、理性克制、几何秩序。
* **调色逻辑**：饱和度降低 -20%，色温大幅偏冷（-20），暗部压黑并染冷蓝（`#0a1628`），暗角强度高达 0.65，主体线条对比度拉高 +25%，完全关闭 Bloom 避免松散感。
* **适用场景**：雪山峰顶、现代建筑线条、荒凉公路、极简构图。

### 3. 日落金辉 🌅
* **视觉语言**：浓郁日落、强穿透丁达尔神光、金色暖阳。
* **调色逻辑**：色温提升 +25，高光染亮金色（`#ffc966`），高光门槛设为 0.55 使得夕阳产生强烈泛光扩散，暗角羽化适中形成深邃聚光。
* **适用场景**：海边日落、沙漠晚霞、秋天胡杨林。

### 4. 丁达尔晨雾 🌲
* **视觉语言**：晨曦圣光穿透薄雾、山间水汽、空灵仙境。
* **调色逻辑**：Bloom 半径放大至 40px，暗部融入清冷松针墨绿（`#1a2a1a`），光晕呈白金色（`#fffbe6`），羽化度 0.9，让光线像自然穿透空气中的水汽。
* **适用场景**：清晨树林、茶园采茶、溪流山涧、云海。

### 5. 蓝调时刻 💙
* **视觉语言**：日落之后半小时的冷暖交织、安静沉思。
* **调色逻辑**：整体冷色温（-15），天空与大面积背景沉降为深邃靛蓝（`#0a1a3a`），焦点主体透出微弱暖黄（`#ffeebb`），形成绝美冷暖撞色。
* **适用场景**：海边暮光、暮色山影、城市华灯初上。

### 6. 极致通透 💎
* **视觉语言**：拒绝对比发灰，还原单反相机级的高动态范围与高锐度。
* **调色逻辑**：自适应拉伸暗部与高光动态范围，冷青高光（`#e0f0ff`），对比度 +20%，无任何暗部染色，纯净通透。
* **适用场景**：高原雪山、纯净湖泊、晴空万里。

### 7. 宫崎骏夏日 🌿
* **视觉语言**：动漫治愈风、高饱和嫩绿、阳光明媚。
* **调色逻辑**：饱和度 +18%，暗部微带生机草绿（`#1a2e1a`），高光泛着柠檬黄白微光（`#f5ffe0`），带轻度 Bloom 柔光，充满青春与治愈力量。
* **适用场景**：夏日草坪、稻田、户外露营、绿意盎然的公园。

### 8. 富士复古胶片 🎬
* **视觉语言**：35mm 胶片胶卷质感、复古暖调、故事感与旅途回忆。
* **调色逻辑**：色温 +15，饱和度微降 -8%，暗部染焦糖暖褐（`#2a1a0a`），叠加 0.18 胶片颗粒噪点，暗角柔和。
* **适用场景**：老街古镇、公路旅行、复古绿皮火车、复古 Vlog。

### 9. 极简视线聚焦 🎯
* **视觉语言**：纯粹物理级聚光，不修改任何画面色彩倾向。
* **调色逻辑**：色彩参数全部归零（0 色温偏移、0 染色、0 Bloom），纯粹以焦点为中心进行主体提亮 +15% 与背景羽化压暗 -50%。
* **适用场景**：任何对原片色彩满意，但希望重点突出某个特定景物的视频。
