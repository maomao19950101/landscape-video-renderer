风景视频电影级光影渲染 (landscape-video-renderer)
Windows 用户使用说明（双击即用）

====================================================================
一、 最简单的使用方法（小白零门槛）：
====================================================================
1. 准备你的风景视频（MP4 或 MOV 格式）；
2. 鼠标按住视频文件，直接【拖拽】到本目录下的「一键拖拽渲染_Windows.bat」图标上松开；
3. 黑色窗口弹出后，输入你想渲染的风格数字（如 1 代表 INFP 浪漫梦幻），按回车；
4. 渲染完成后，成片会自动保存在原视频所在的文件夹，带 _rendered 后缀，可直接发抖音！

====================================================================
二、 Windows 硬件加速专项优化说明：
====================================================================
本工具已在底层针对 Windows PC 完成了硬件加速自适应检测：
- NVIDIA 显卡用户（RTX / GTX 独显）：自动调用 NVIDIA NVENC 硬件芯片极速转码；
- Intel 处理器用户（酷睿核显 / Arc 独显）：自动调用 Intel QuickSync (QSV) 硬件加速；
- AMD 显卡用户（Radeon 显卡）：自动调用 AMD AMF 硬件加速；
- 多核 CPU 并行：自动调动电脑全部 CPU 核心并行处理。

====================================================================
三、 运行环境要求（首次运行前确认）：
====================================================================
1. 电脑需安装 Python（推荐 3.10 或更高版本），安装时务必勾选 "Add python.exe to PATH"；
2. 电脑需安装 FFmpeg 并加入系统 PATH，或者直接将 ffmpeg.exe 复制到本目录的 bin 文件夹中即可；
3. 如安装了 uv（推荐：powershell -c "irm https://astral.sh/uv/install.ps1 | iex"），则无需预先手动安装任何 Python 依赖，开箱即用。
